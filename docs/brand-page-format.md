# ブランド紹介ページ フォーマット仕様

ダミアーニのページ（`damiani-brand-page.html`）で確定したフォーマットを、他のブランドにも使えるようにまとめたもの。

- テンプレート：`template/brand-page-template.html`
- 入稿シート（ブランドごとに記入）：`template/brand-input-sheet.md`
- 完成見本：`damiani-brand-page.html`

---

## 1. 基本方針

| 項目 | 仕様 |
|---|---|
| 想定端末 | スマホ9割（基準の幅は390px）。PCは幅900px以上で2カラムのグリッドに切り替え、最大幅は1180px |
| ファイル形式 | 1ファイルのHTML。CSSは `<style>` に内蔵し、JavaScriptは使わない |
| 外部から読み込むもの | Google Fonts と画像URLのみ |
| トンマナ | エディトリアル・モダン（元デザイン「1e」）。白地に2pxの黒罫線でグリッドを見せ、ゴールドは罫線・ラベル・CTAだけに使う |
| 画像の色 | カラー（白黒処理はしない） |

## 2. ページ構成

| # | セクション | ID | 目的 | 必須 | 画像 |
|---|---|---|---|---|---|
| 00 | ヒーロー | – | 世界観の提示。キャッチコピー、リード文、3つの数字 | 必須 | 画像① |
| 01 | ストーリー | `#story` | ブランドの歴史と代表者メッセージ | 必須 | なし |
| 02 | クラフト | `#craft` | 製法・職人技（画像は左、テキストは右） | 必須 | 画像② |
| 03 | フィロソフィー | `#philosophy` | 大きな引用と3本柱 | 必須 | なし |
| 04 | クオリティ | `#quality` | 素材・品質（テキストは左、画像は右） | 必須 | 画像③ |
| 05 | コレクション紹介 | `#collection` | トップ画像、導入文、3アイテム（例：ブライダル） | 任意 | トップ1枚＋アイテム3枚 |
| 06 | CTA | – | 公式サイトへの誘導。背景は画像に暗い膜（黒62%）を重ねる | 必須 | 画像④ |
| – | フッター | – | ブランド名と「SINCE 創業年 — 所在地」 | 必須 | なし |

- セクション見出しのラベルは「番号 — 英字ラベル」の形にする（例：`01 — BRAND HISTORY`）。05を削除する場合、06のCTAには番号を表示しないので、振り直しは不要。
- 上部メニュー（ナビ）の文言は英大文字の短い語にする（例：HISTORY / SAVOIR-FAIRE / ART / MATERIALS / BRIDAL）。

## 3. デザイン指定

### 色（CSS変数）
| 変数 | 値 | 用途 |
|---|---|---|
| `--ink` | #201e1d | 見出し、罫線、CTAとフッターの背景 |
| `--text` | #3a3633 | 本文 |
| `--sub` / `--muted` | #5a5551 / #8a8379 | 引用者名、補足 |
| `--gold` | #b08a4a | 細い罫線 |
| `--gold-label` | #8a6a2f | 英字ラベル（白地の上） |
| `--gold-light` | #c9a663 | CTAボタン、フッターのロゴ（黒地の上） |
| `--hair` | #e2ded8 | 区切りの細線 |

ブランドカラーに寄せる場合は、`--gold` 系の3色だけを差し替える。

### フォント
| 用途 | フォント | 主なサイズ（スマホ / PC） |
|---|---|---|
| 見出し・引用 | Shippori Mincho B1 | ヒーロー 30 / 40px、セクション見出し 28px、大きな引用 22 / 30px |
| 英字ラベル・数字 | Archivo | ラベル 10px、字間 .28em |
| 本文 | Noto Sans JP | 13〜14px、行間 2.2 |

## 4. 画像仕様

| 画像 | 位置 | スマホでの比率 | PCでのサイズ | 推奨素材 |
|---|---|---|---|---|
| ① | ヒーロー | 4:3 | 約660×520px | 横長。商品か世界観のわかるもの |
| ② | 02 クラフト | 4:3 | 幅590px、高さは本文に合わせて伸びる | 工房・手仕事 |
| ③ | 04 クオリティ | 4:3 | 幅590px、高さ560px以上 | 素材・ディテール |
| ④ | 06 CTA背景 | 本文に合わせて伸びる | 1180×380px | 暗くしても成り立つ横長 |
| コレクションのトップ | 05 | 1:1 | 幅590px、高さ560px以上 | 正方形に近いもの |
| アイテム1〜3 | 05 | 4:3 | 3列 | 各アイテムの商品が写ったもの |

- 表示は `object-fit: cover` なので、比率が合わない分は自動でトリミングされる。
- 被写体が中央から外れている画像は、`<img>` の `style="object-position:X% 50%"` で左右の位置を調整する（0% が左端、100% が右端）。
- 表示崩れを防ぐため、`width` と `height` には元画像の実際のピクセル数を入れる。
- `alt`（代替テキスト）には写っている内容を具体的に書く。④は装飾なので `alt=""` のままでよい。

### 画像URLのルール
```
{{IMG_BASE}} = https://hidakahonten.jp/wp-content/uploads/YYYY/MM/
src = {{IMG_BASE}} + 画像名
```
- `YYYY/MM` はWordPressにアップロードした年月（例：`2023/08/`、`2026/09/`）。同じページの中でも画像ごとに年月が違ってよい。その場合は `{{IMG_BASE}}` を使わず、URLを直接書く。
- 画像名の例：`{ブランド}_{用途}.{拡張子}`（例：`damiani_engagementring.png`）

## 5. 制作手順

1. 入稿シート（`template/brand-input-sheet.md`）をコピーし、ブランドの情報を記入する。
2. `template/brand-page-template.html` を `{brand}-brand-page.html` としてコピーする。
3. `{{…}}` をすべて置き換える。`grep -n "{{" {brand}-brand-page.html` で何も出なければ完了。
4. 05を使わない場合は、次の2か所を削除する。
   - `<!-- OPTIONAL: … -->` から `<!-- /OPTIONAL -->` までの範囲
   - ナビの `#collection` の行
5. 段落の数は増減してよい。`<p class="body">` の行を複製または削除する。
6. 幅390pxと1280pxで表示を確認する。横スクロールが出ないこと、画像がすべて表示されることを見る。
7. 下の「広告審査チェック」を実施してから公開する。

## 6. 文字量の目安（崩れないための上限）

| 箇所 | 目安 |
|---|---|
| ヒーローの見出し | 1行あたり9文字以内×2行（PCでは改行しない） |
| 数字（STAT） | 値は7文字以内、英字ラベルは18文字以内 |
| セクション見出し | 1行あたり8文字以内 |
| アイテム名（05） | 16文字以内（PCの3列で1行に収まる長さ） |
| 大きな引用（03） | 80文字前後まで |

## 7. 広告審査チェック（公開前）

- [ ] **数値・年数：** 「○年の伝統」「○世代」などは、創業年と一致しているか。数字には「○年現在」の時点を意識する。
- [ ] **最上級・断定の表現：** 「唯一無二」「傑作」「永遠に輝き続ける」「世界中で認められている」などは、景品表示法（優良誤認）の観点から、根拠資料があるか、ブランドの公式文言か、を確認する。
- [ ] **「100%」「すべて」などの表現：** 「100% HANDMADE」「全てがイタリア製」などは、取扱商品の実態と一致しているか。
- [ ] **素材・仕様：** 素材の種類、ダイヤの有無、着け心地の仕様などは、実際に扱う商品と一致しているか。
- [ ] **画像と見出しの一致：** 見出しの商品と画像に写っている商品の種類が一致しているか（例：エンゲージメントリングの欄に、センターストーンのあるリングの画像を使う）。
- [ ] **権利：** 画像の出典と利用許諾、ブランド名・ロゴの使用許諾があるか。
- [ ] **引用：** 人物の発言として引用する文には、出典（ブランドの公式資料など）があるか。
- [ ] **リンク先：** 公式サイトのURLが有効か。
