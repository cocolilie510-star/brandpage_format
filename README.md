# brandpage_format

ブランド紹介ページ（スマホ優先・1ファイルのHTML）のフォーマット集。

| ファイル | 内容 |
|---|---|
| `docs/brand-page-format.md` | フォーマット仕様（構成、デザイン、画像、制作手順、広告審査チェック） |
| `template/brand-page-template.html` | HTMLテンプレート（`{{…}}` を置き換えて使う） |
| `template/brand-input-sheet.md` | ブランドごとの入稿シート |
| `damiani-brand-page.html` | 完成見本（DAMIANI） |
| `images/` | DAMIANIの工房画像を4:3にトリミングしたもの（ローカル控え。ページからは参照していない） |

## 使い方（概要）
1. `template/brand-input-sheet.md` をコピーして記入する。
2. `template/brand-page-template.html` をコピーして `{{…}}` を置き換える。
3. スマホとPCで表示を確認し、広告審査チェックを行ってから公開する。

詳細は `docs/brand-page-format.md` を参照。
